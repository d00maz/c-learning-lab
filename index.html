Storage model

Lifetime is the key

A pointer is an object that stores a reference to another object. Before dereferencing it, make sure the pointed-to object still exists and is valid.

int x = 42;
int *p = &x;
printf("x=%d\\n", *p);
  • Automatic storage: commonly local variables; lifetime ends when execution leaves their block.
  • Allocated storage: request with malloc/calloc; release with free.
  • Habit: decide who owns an allocation and who is responsible for freeing it.

Library field guide

Know where to look things up.

Prefer standard references and manual pages over guessing. Check which C standard and platform your compiler targets.

<stdio.h>

Formatted I/O, streams, files, and functions such as printf, fgets, fopen, and fclose.

<stdlib.h>

Allocation (malloc, free), conversions, sorting, and process utilities.

<string.h>

Byte-string operations. Know destination capacity and null-termination requirements.

<ctype.h>

Character classification and case conversion. Pass EOF or a value representable as unsigned char.

<errno.h>

Error reporting support. Check each function's documentation for its error-reporting contract.

<math.h>

Common mathematical functions. Some toolchains require linking the math library explicitly.

Trusted references

  • cppreference — C language and library reference
  • GNU C Library Manual
  • Linux man-pages project
  • WG14 N1570 — public C11 committee draft
  • ISO/IEC 9899:2024 — C23 standard listing

N1570 is a committee draft, not the published ISO standard. Platform manuals describe platform behavior; they do not replace the language standard.

Good habits beat clever tricks

Do

Initialize objects, check return values, validate input, and keep ownership and cleanup clear.

Avoid

Out-of-bounds access, uninitialized reads, dangling pointers, unchecked input, and assuming undefined behavior is predictable.
